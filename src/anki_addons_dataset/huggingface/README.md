# Anki Addons Dataset

Information about the 3,000+ addons of the [Anki flashcard program](https://apps.ankiweb.net) listed in the
[Addon Catalog](https://ankiweb.net/shared/addons), enriched with data from [GitHub](https://github.com) and the
[Anki Forum](https://forums.ankiweb.net). A new snapshot is usually published once a month.

- Browse it: [HuggingFace Spaces app](https://huggingface.co/spaces/Ya-Alex/anki-addons)
- Questions, feedback, bugs: [support topic at Anki Forum](https://forums.ankiweb.net/t/anki-addons-dataset-a-detailed-list-of-addons/63090)
- Source code: [anki-addons-dataset](https://github.com/Aleks-Ya/anki-addons-dataset)

## Usage

```python
from datasets import load_dataset

addons = load_dataset("Ya-Alex/anki-addons", split="train")
reviews = load_dataset("Ya-Alex/anki-addons", "reviews", split="train")

import pandas as pd

addons = pd.read_parquet("hf://datasets/Ya-Alex/anki-addons/latest/parquet/data.parquet")
```

## Tables

| Config                                                                                                        | Contents                                               |
|---------------------------------------------------------------------------------------------------------------|--------------------------------------------------------|
| [`default`](https://github.com/Aleks-Ya/anki-addons-dataset/blob/main/docs/dataset/addons.md)                 | One row per addon                                      |
| [`tags`](https://github.com/Aleks-Ya/anki-addons-dataset/blob/main/docs/dataset/tables.md#tags)               | The AI tag vocabulary with the meaning of every tag    |
| [`anki_versions`](https://github.com/Aleks-Ya/anki-addons-dataset/blob/main/docs/dataset/tables.md#anki_versions) | Stable Anki releases from 2.1.0 on, newest first   |
| [`reviews`](https://github.com/Aleks-Ya/anki-addons-dataset/blob/main/docs/dataset/tables.md#reviews)         | User reviews from the AnkiWeb addon pages              |
| [`packages`](https://github.com/Aleks-Ya/anki-addons-dataset/blob/main/docs/dataset/tables.md#packages)       | `.ankiaddon` packages served by AnkiWeb, one per branch |

`latest/` holds the newest snapshot, `history/YYYY-MM-DD/` every snapshot, as Parquet and (except `reviews` and
`packages`) Excel files.

## Good to know
- `ai.summary` and `ai.tags` are generated by a large language model and may be inaccurate.
- `anki_web.description_html` is **not sanitized**: sanitize it before rendering.
- Fields added after a snapshot was collected are `null` in it.
